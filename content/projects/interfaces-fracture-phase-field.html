Project

Interfaces, Fracture, and Phase-Field Methods

This project brings together interface evolution, fracture modeling, and phase-field methods for solids with complex coupled behavior. The aim is to connect physically meaningful mechanisms with formulations that remain computationally robust.

Particular attention is given to how interface energetics, defect evolution, and regularized fracture descriptions can be expressed in a mathematically coherent framework suitable for simulation.
